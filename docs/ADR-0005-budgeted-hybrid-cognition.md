# ADR-0005: LLM 调用必须受预算和降级保护

## 状态

Accepted

## 背景

真实 LLM 调用可以改善计划候选质量，但它有延迟、成本、失败和不可复现风险。直接在每个 tick 为每个角色调用模型，会让模拟速度和稳定性不可控。

## 决策

新增 `HybridCognition`：

- 只有白名单角色可以调用主 provider。
- 只有指定天数间隔可以调用。
- 每次运行有最大调用次数。
- 失败次数达到上限后只使用规则认知。
- 任何异常都会降级到 `RuleBasedCognition`。

## 后果

LLM 可以进入模拟循环，但默认关闭。我们可以逐步扩大调用范围，并用指标判断它是否真的改善社会演化。
