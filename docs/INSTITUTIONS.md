# Institutions

制度层的目标不是写固定剧情，而是给社会增加可演化的中间结构。

当前实现包含三类状态：

- `Agent.reputation`: 个体声望。生产、修理、采集和社交会提高声望；在高压力下逃避共同责任会降低声望。
- `Organization`: 组织。每个组织有成员、类型、规范、凝聚力和组织声望。
- `Metrics.institutional_cohesion`: 全社会组织凝聚力均值，用来判断制度是否正在失效。

初始社会包含两个家庭和一个公共议会：

- `household_north`
- `household_south`
- `common_council`

观察者可以通过 `organization` 干预创建新组织。组织不是剧情分支；它只改变成员关系和制度状态，后续影响仍由行动规则、资源压力和健康指标自然演化出来。

关键规则：

- 生产性行动提高个人声望。
- 社交行动提高个人声望，并可修复关系。
- 组织成员贡献度高时，组织凝聚力上升。
- 共享压力高且贡献不足时，组织凝聚力下降。
- 高凝聚力组织会给成员提供少量归属感和意义支撑。
- 制度凝聚力低于阈值时，会触发 `institutional_crisis`，削弱归属、意义和信任。

这一层让后续的贸易、冲突、联盟、治理、宗教、职业协会和城市制度有地方生长，而不需要预设固定分支。
