# 项目宪章

## 愿景

创建一个长期运行的生成式虚拟社会。它拥有资源循环、空间结构、人口、组织、关系、制度、历史记忆、冲突、协作和文化演化。用户可以观察、参与和影响这个社会，但社会的发展主要来自世界约束和 agent 的生成式推理，而不是预设剧情分支。

最终呈现不是一个单纯的 3D 游戏，也不是 NPC 聊天室，而是一个“可观察、可参与、可回放的生成式虚拟社会实验室”。

## 三个不可妥协的目标

1. 自行发展不崩溃  
   社会能在设定背景下长期运行。崩溃可以作为社会现象出现，但不能因为模拟架构失控、状态爆炸或 LLM 胡编导致系统性失真。

2. 可观察、可参与、可影响  
   用户既能以上帝视角观察，也能作为角色进入，还能通过资源、灾害、信息、制度、组织或环境变化影响社会。

3. 非分支式演化  
   不用大量 if/else 剧情树假装自由，而是用世界规则、agent 目标、记忆、关系、资源约束和制度反馈生成变化。

## 产品判断

更准确的类比是：

The Sims 的可观察日常生活 + Dwarf Fortress 的系统涌现 + Stanford Smallville 的生成式 agent + 社会科学实验室的评估和回放。

但本项目不能只复制其中任何一个：

- 只像 The Sims，会变成角色动画和需求条。
- 只像 Dwarf Fortress，会缺少可解释内心和语言互动。
- 只像 Stanford Smallville，会缺少长期世界约束和社会评估。
- 只像研究 demo，会缺少用户可进入、可影响的产品体验。

## 架构原则

- Simulation Core 是唯一世界事实来源。
- LLM 只提出结构化意图，不直接写世界状态。
- 世界规则负责约束、验证、结算和回放。
- agent 层负责身份、记忆、反思、计划、对话和社会解释。
- 观察层必须能展示因果链，而不只是漂亮画面。
- 每个里程碑都必须交付一个用户可见能力、一个测试或评估、一个可运行 artifact。

## 当前阶段

项目已经完成一个稳定的 headless 社会模拟底座，并拥有 2D/3D 观察器、API、干预协议、组织、地点、物流和离线报告。

现在进入生成式社会 Alpha 阶段：

- 引入 agent 身份档案。
- 引入结构化记忆流。
- 引入记忆检索。
- 引入周期反思。
- 把这些上下文提供给后续 LLM provider。

## 非目标

短期内不优先做：

- 大型 3D 地图。
- 多人在线服务器。
- 复杂剧情编辑器。
- 大规模 NPC 群体。
- 纯 LLM 聊天室。

这些都重要，但必须建立在可运行、可评估、可回放的生成式社会内核之上。
