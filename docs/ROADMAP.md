# 路线图

## M0: 社会内核胚胎

目标：让一个小社会在命令行中连续运行。

完成标准：

- 世界可以用 seed 初始化。
- 至少有 5 个智能体。
- 有资源生产、消耗、休息、社交。
- 有事件日志和健康指标。
- 可以运行 30 天以上，不因为程序错误中断。

当前仓库已经开始实现 M0。

## M1: 可干预社会

目标：观察者可以通过 API 影响社会。

完成标准：

- 增加干预命令，例如投放资源、制造灾害、调整规则、引入新角色。
- 每个干预都进入事件日志。
- 指标能显示干预前后的社会变化。
- 增加回放测试。

当前状态：已实现第一版。命令行可以加载 JSON 干预文件，也可以进行多 seed 实验。

## M2: 角色记忆和计划

目标：智能体不只是按即时需求行动，而是拥有历史记忆和短期计划。

完成标准：

- 每个角色有事件记忆。
- 角色能基于记忆形成偏好。
- 增加计划系统，但计划必须被世界规则校验。
- 先使用本地规则实现，再接 LLM。

当前状态：已实现第一版规则式认知层。角色会生成 `Plan`，模拟核心会校验计划并记录 `plan` / `plan_blocked` 事件。尚未接入外部 LLM。

## M3: LLM 认知层

目标：让 LLM 负责自然语言、解释、计划生成和文化表达。

完成标准：

- LLM 输入只包含压缩后的可信上下文。
- LLM 输出必须是结构化意图，不直接改状态。
- 模拟核心校验 LLM 意图是否可执行。
- 有成本、延迟和失败降级策略。

当前状态：已完成 API 接入前的本地契约，包括上下文打包、提示词渲染和结构化计划解析。下一步若要调用真实模型，需要配置 API。

更新：已接入本机 Codex CLI provider，并实现混合认知运行时。真实模型调用默认关闭，启用时受角色白名单、调用间隔、调用预算和失败降级保护。

## M4: 2D/调试观察器

目标：在进入正式 3D 前建立可视化调试面板。

完成标准：

- 时间轴。
- 事件流。
- 人物状态面板。
- 资源和关系图。
- 可执行干预按钮。

当前状态：已实现离线 HTML 观察器，可以保存单次运行的指标曲线、健康状态、角色表和事件流。下一步再做交互式干预按钮。

## M5: 3D 观察与参与

目标：把社会状态映射到 3D 世界。

完成标准：

- 角色和地点可视化。
- 用户可以作为观察者或角色进入。
- 用户行为通过 Interaction API 影响模拟。
- 3D 客户端可以断线重连，不破坏核心模拟。

## M6: 长期运行实验

目标：让社会连续运行数百到数千天，并分析演化。

完成标准：

- 自动保存快照。
- 自动检测崩溃、停滞、资源爆炸、关系全断裂等异常。
- 生成社会历史摘要。
- 形成可复现实验报告。

当前状态：已实现多 seed JSON/HTML 实验报告。下一步增加自动快照目录、固定实验套件和历史摘要。

## M7: 多社会和文明演化

目标：从一个小社区扩展到多个群体、组织和制度。

完成标准：

- 多地点迁移。
- 组织和制度出现。
- 贸易、冲突、联盟、文化分化。
- 社会之间可以互相影响。
