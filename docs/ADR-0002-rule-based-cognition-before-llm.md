# ADR-0002: 先实现规则式认知层，再接 LLM

## 状态

Accepted

## 背景

项目长期需要 LLM，但当前没有 API 配置，而且社会核心还在早期阶段。如果过早让 LLM 直接决定角色行为，会引入不可复现、难测试、成本不稳定和幻觉污染状态的问题。

## 决策

先实现可插拔的 cognition provider 接口，并默认使用 `RuleBasedCognition`。

认知层只产出候选计划：

- 行动类型。
- 优先级。
- 原因。
- 可选目标。

模拟核心负责校验计划并执行行动。计划被阻止时，核心会写入 `plan_blocked` 事件并选择安全降级行动。

## 后果

- 现在不需要任何外部 API。
- 角色已经能基于需求、资源、职业、关系和近期记忆形成计划。
- 未来接 LLM 时，只需要新增一个 provider，不改变世界事实层。
